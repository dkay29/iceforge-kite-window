# Implement forecast REST API

Labels: backend,api

## Goal

Expose spots, current forecast, date forecast, and seven-day outlook through API Gateway.

## Acceptance criteria

- API implements documented endpoints and error envelope.
- ETag, If-None-Match, and 304 behavior supported.
- Stale-data metadata is returned.
- Public forecast reads are cacheable.
- OpenAPI specification is generated and tested.
