# Validate and publish West Dennis spot configuration

Labels: domain,data,safety

## Goal
Create the production-quality West Dennis spot configuration.

## Acceptance criteria
- Latitude, longitude, timezone, and beach orientation verified.
- NOAA CO-OPS tide station selected and documented.
- Accepted and prohibited wind sectors reviewed.
- Default three-hour low-tide ruleset published.
- Configuration is versioned and stored under deterministic S3 keys.
